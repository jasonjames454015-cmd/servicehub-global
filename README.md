## Deployment (Free)
1. This repo is public.
2. **GitHub Pages (current recommended free option while Netlify credits constrained):** In repo Settings > Pages, set Source to "GitHub Actions". The workflow publishes the `servicehub` folder on pushes.
3. Or Cloudflare Pages (unlimited static bandwidth) or existing Netlify free tier (MVP remains live).
4. Build: none. Publish directory: `servicehub`.
