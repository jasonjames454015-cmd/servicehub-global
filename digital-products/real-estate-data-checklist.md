# Free Public Real Estate Data Research Checklist

**Version:** 0.1 Draft  
**Date:** 2026-10-10  
**Use:** Educational / research only. Always verify current public access and comply with site terms. No scraping behind logins.

## Pre-Flight
- [ ] Confirm you are using only free, publicly accessible sources.
- [ ] No paid API keys or accounts required for basic research.
- [ ] Document the source and access date for every data point.

## Step 1: Identify Location
- [ ] Obtain full address or ZIP code.
- [ ] Use free Census Geocoder (geocoding.geo.census.gov) to get county, FIPS, census tract.
- [ ] Note latitude/longitude if available from free tools.

## Step 2: County Property Records
- [ ] Search "[County] [State] assessor" or "property search" (official .gov).
- [ ] Retrieve: owner name (if public), assessed value, tax amount, property type, square footage (if listed).
- [ ] Check for any public sales history or deed info.
- [ ] Screenshot or note the official URL and date accessed.

## Step 3: Census Demographics
- [ ] Go to data.census.gov.
- [ ] Look up the census tract or ZIP for: median household income, housing occupancy rate, median home value, population.
- [ ] Record the ACS year (usually 5-year estimates).

## Step 4: Flood & Hazard (Free)
- [ ] Use FEMA Flood Map Service Center (msc.fema.gov) public viewer.
- [ ] Determine flood zone for the address.
- [ ] Note any other free hazard maps (state GIS if available).

## Step 5: Compile & Document
- [ ] Create a simple one-page summary with sources.
- [ ] List all URLs accessed.
- [ ] Flag any data that required login or payment (do not use those).

## Notes
- Availability varies by county. Some have excellent free portals; others require in-person or mail requests.
- This checklist is the foundation for a future digital product (PDF or Notion template).
